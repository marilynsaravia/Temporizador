## Descripción
Esta aplicación es un **Temporizador** desarrollado en HTML5, CSS3 y Javascript Vanilla. 

### Características Actuales:

- **Control Principal::** Control total con funciones de Reproducir, Pausar, Siguiente y Pista anterior.
- **Interfaz Dinámica::** Actualizaciones en tiempo real de títulos, artistas y portadas mediante manipulación del DOM.
- **Flujo Continuo::** Función de reproducción automática que inicia la siguiente pista al finalizar la actual.
- **Alojamiento Externo::** Transmisión eficiente de archivos de audio y recursos alojados en Archive.org.
- **Diseño Responsivo::** Una interfaz elegante y adaptativa que se ajusta perfectamente a diferentes dispositivos.
